# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## What this is

A Korean-language single-page portfolio site for a level/game designer (조영환). 100% static — no build, no package manager, no tests. Just one HTML file and an `images/` folder.

- `index.html` — the live interactive site (~775 lines, all CSS + JS inline).
- `images/` — all assets, named `<project-slug>-<descriptor>.{png,jpg,gif}` (e.g. `dronewar-thumb.png`, `thedoor-timeline-3a.png`).

## Running / previewing

Open `index.html` directly in a browser, or serve the directory with any static server (e.g. `python3 -m http.server`). YouTube embeds and Google Fonts require internet.

## Architecture of `index.html`

The page is one document with two views toggled via `display`, not a router:

- `#main-view` — hero, projects grid, personal-work grid, about, contact.
- `#detail-view` — per-project page, populated dynamically.

All content data lives in two arrays inside the inline `<script>`:

- `PROJECTS` (~line 285) — main timeline projects. Order in the projects grid and horizontal timeline is determined by sorting on the leading date in `meta` (e.g. `'2025.09 - 2025.10 · ...'`); `meta.match(/[\d.]+/)[0]` is the sort key, so `meta` MUST start with a parseable date.
- `PERSONAL_WORKS` (~line 479) — side studies; rendered into `#personal-grid` in array order (no sort).
- `ALL_WORKS = [...PROJECTS, ...PERSONAL_WORKS]` is the lookup table for `showDetail(id)`. Adding a new project anywhere requires only appending to one of these arrays.

### Project object schema

Every project shares a base shape; optional keys turn on detail-page sections:

```js
{
  id, title, abbr, meta, shortDesc, tags, fullDesc,  // required
  thumb,            // grid + detail hero background; falls back to `abbr` placeholder
  info: [{label, value}],  // rendered as a divider strip; if any label === '수상',
                           //   a 👑 badge appears on the horizontal timeline
  links: [{type: 'primary'|'ghost', label, href}],
  youtubeId,        // adds a "Gameplay" section with nocookie embed
  mapImg,           // adds a "Level Map" section
  sections: [{ title, img?, blocks: [...] }],  // free-form content
  timeline: [{ time, desc, img: string | [string, string] }],  // adds "Level Design Timeline"
}
```

`sections.blocks[].type` recognized by the renderer (`showDetail`, ~line 627): `text`, `subtitle`, `callout`, `list` (`items: []`), `img` (`src` optional — empty src renders a "이미지 준비 중" placeholder), `img-text-row` (left image + right list).

`timeline[].img` may be a single string or a 2-element array; arrays render as a 2-column grid (used for before/after pairs like `thedoor-timeline-2.png` + `thedoor-timeline-2b.png`).

### Navigation & state

- `showDetail(id)` / `showMain()` swap view visibility, scroll to top, update `document.title`, and `history.pushState` a hash like `#drone-war`.
- A `popstate` listener restores the right view on back/forward.
- On load, `location.hash` is matched against `ALL_WORKS` to deep-link into a detail page.
- `goSection(id)` from the nav forces back to main view first, then scrolls.

### Visual conventions (don't break these)

- Custom cursor: `body { cursor: none }` everywhere, plus two divs (`.cursor`, `.cursor-ring`) follow the mouse via `requestAnimationFrame`. Any new interactive element (button, link) must also set `cursor: none` or it'll show the OS arrow.
- Reveal-on-scroll: any element with class `reveal` fades up via `IntersectionObserver`. After dynamically inserting cards or detail content, call `observeReveal()` (already done inside `renderCards`).
- Color tokens are CSS variables on `:root` (`--bg`, `--red`, `--cream`, `--muted`, `--border`, `--surface`, `--surface2`). Use them rather than hard-coded hexes.
- Fonts: `--font-display` (Bebas Neue) for headings, `--font-body` (Noto Sans KR) for body, `--font-mono` (JetBrains Mono) for labels/meta.

## Adding content

- **New project**: append an object to `PROJECTS` or `PERSONAL_WORKS`. Make `meta` start with a `YYYY.MM` date so the sort works. Drop images into `images/` using the `<slug>-...` convention.
- **Editing copy on detail pages**: edit the project object, not the HTML — the detail DOM is fully generated by `showDetail`.
- **Editing the static About / Contact / hero copy**: those are hand-written in the HTML body (~lines 183-251).
